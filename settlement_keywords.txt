# Settlement-pressure trigger vocabulary.
#
# THIS FILE IS MEANT TO BE EDITED BY A PUNJABI/HINDI SPEAKER, NOT A PROGRAMMER.
# One phrase per line. Lines starting with # are ignored. No code changes are
# needed after editing, because classify.py reads this file at import.
#
# Add every spelling people actually type, as its own line. Do not try to be
# clever or compact: "angutha", "angootha" and "anguutha" are three lines.
#
# Matching: Latin-script phrases match whole words only ("sign" does not fire
# on "design"). Devanagari and Gurmukhi phrases match anywhere in the word,
# because Hindi and Punjabi attach postpositions to the noun and a whole-word
# rule would miss कागज़ों / ਕਾਗਜ਼ਾਂ.
#
# Over-triggering is the correct failure direction. A family that reads this
# warning unnecessarily loses thirty seconds. A family that misses it can sign
# away their entire claim. When in doubt, add the word.
#
# ⚠️ Still needs a native-speaker pass. These were drafted by a non-speaker.
# A Ludhiana union rep will produce a better list in ten minutes.
